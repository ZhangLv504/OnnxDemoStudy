# 知识点课程总览：ONNX Runtime 算子与深度学习推理流程

> 分支：`feature/onnx-kp-demos`
> 目标：通过「知识点 demo」把 **ONNX 算子** 与 **深度学习推理流程** 之间的关联讲透，最终能自己看懂并编写基于 ONNX Runtime C/C++ API 的推理程序。

本仓库提供的是 ONNX Runtime 1.26.0 的 C/C++ SDK 头文件（CPU 版 `onnxruntime1.26.0-win/` 与 GPU 版 `onnxruntime1.26.0-win-gpu/`），所有 demo 的代码示例直接对应这些头文件里暴露的 API。

## 一句话主线

> **一个深度学习模型在 ONNX 中是一张「计算图（Graph）」，图上每个节点是一个算子（Operator）。推理（Inference）就是按图拓扑顺序执行算子，把输入张量加工成输出张量。** ONNX Runtime 就是这个「图编辑器+执行引擎」。

## 推荐学习方式

1. 按顺序阅读每个 demo 的 markdown 文档；
2. 动手写示例（或对照虚拟代码）跑通一个最小的推理；
3. 完成每个文档末尾的「自测题」，再进入下一个知识点。
